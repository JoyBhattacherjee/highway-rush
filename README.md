# Highway Rush

A cartoon 8-racer highway race where everyone drives a Bengal Toto (e-rickshaw). Pseudo-3D canvas engine with a React UI, in a single HTML file.

## Play
Open `index.html` in a browser (needs internet for React and Google Fonts from CDNs).

## Controls
- Steer: Left/Right arrows or A/D
- N2O boost: Space
- Drift: Shift
- Brake: Down arrow or S
- Pause: P or Esc, Mute: M

Throttle is automatic. Drifting and slipstreaming fill your N2O. Touch controls appear on phones.
